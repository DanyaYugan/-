============================================
   ИНСТРУКЦИЯ — LINKS
============================================

Утилита для хранения ссылок. Состоит из двух
файлов:
  App.html      — страница со ссылками
                  (её отправляют другим)
  Settings.html — редактор (только для вас)

Оба файла должны лежать в одной папке.


--------------------------------------------
ПЕРВЫЙ ЗАПУСК
--------------------------------------------

1. Откройте Settings.html в Chrome, Edge,
   Яндекс.Браузере или Opera.

2. Нажмите «📂 Открыть App.html» и выберите
   файл из той же папки.

3. Настройте тему, заголовок, теги и ссылки.

4. Нажмите «💾 Сохранить в App.html»
   и подтвердите доступ.

5. Откройте App.html — там ваши ссылки.


--------------------------------------------
РЕДАКТОР (Settings.html)
--------------------------------------------

Вкладки:

  Общее     — тема (светлая / тёмная /
              системная), заголовок
              и подзаголовок страницы

  Теги      — название, цвет, добавление
              и удаление тегов

  Ссылки    — название, описание, URL,
              текст кнопки, привязка тегов

  Бэкап     — экспорт и импорт JSON
              (резервная копия настроек)

Кнопка сверху «Сохранить в App.html»
записывает все изменения в файл.


--------------------------------------------
ПРОСМОТР (App.html)
--------------------------------------------

  • Поиск — фильтр по названию, описанию,
    URL и тегам. Работает в реальном
    времени.

  • Копировать ссылку — иконка рядом
    с кнопкой, копирует URL в буфер.

  • Вид сетка / список — переключатель
    справа сверху. Выбор запоминается.


--------------------------------------------
КАК ПОДЕЛИТЬСЯ
--------------------------------------------

Отправьте ТОЛЬКО App.html.

У получателя откроется готовая страница
со всеми вашими настройками. Интернет
и второй файл не нужны.


--------------------------------------------
ГДЕ ХРАНЯТСЯ ДАННЫЕ
--------------------------------------------

Внутри App.html — в блоке

  <script id="app-data">

При сохранении редактор перезаписывает
только этот блок.


--------------------------------------------
ЧАСТЫЕ ПРОБЛЕМЫ
--------------------------------------------

Кнопки в редакторе не работают
  → Открыто в Firefox или Safari.
    Откройте в Chrome, Edge,
    Яндекс.Браузере или Opera.

«Не удалось сохранить»
  → Файл перемещён. Откройте
    Settings.html заново и выберите
    App.html.

Файл называется App.html.txt
  → В Проводнике включите
    «Вид → Показать →
    Расширения имён файлов»
    и переименуйте.

Ошибка «Unsafe attempt to load URL file://...»
  → Обычное предупреждение Chrome
    для локальных файлов. Игнорируйте.


--------------------------------------------
ШПАРГАЛКА
--------------------------------------------

Посмотреть ссылки    → открыть App.html
Изменить что-либо    → Settings.html,
                       правка, сохранить
Найти ссылку         → строка поиска
Скопировать URL      → иконка копирования
Сменить вид          → сетка / список
Сделать бэкап        → вкладка «Бэкап»,
                       экспорт JSON
Отправить другому    → файл App.html


--------------------------------------------
СОВЕТ
--------------------------------------------

Раз в неделю делайте экспорт JSON —
на случай, если случайно испортите
App.html.
